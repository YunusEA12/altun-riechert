# KI-Ratgeber (A&R Praxiswissen 01)

`downloads/ki-ratgeber.pdf` wird aus `build.py` (Text + Diagramme, `charts.py`) erzeugt und mit `topdf.js` (Playwright/Chromium, A4) gedruckt. Schrift: `fonts/archivo-var.woff2` neben `build.py` legen.

Vor jeder Veröffentlichung: Inhalte von Yunus und Calvin prüfen lassen (KI-VO Art. 50 Abs. 4: Ausnahme von der KI-Kennzeichnung nur bei menschlicher Prüfung und redaktioneller Verantwortung; im PDF steht das so im Hinweis-Kasten). Alle Zahlen stehen mit Quelle im Quellenverzeichnis, Abrufdatum 30.10.2026. Nur eigene Diagramme, keine fremden Grafiken.

Per E-Mail als Newsletter nur mit Double-Opt-in verschicken (§ 7 UWG, Art. 6 DSGVO). Als Download auf der Website und als Beilage zum Brief ohne Einwilligung möglich.
